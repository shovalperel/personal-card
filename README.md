# כרטיס ביקור דיגיטלי — שובל לוגסי

אתר אישי חד-עמודי המשמש ככרטיס ביקור עסקי דיגיטלי: מציג רקע מקצועי, כישורים,
פרויקטים ופרטי יצירת קשר.

## טכנולוגיות
- **HTML5** — מבנה סמנטי (`header`, `main`, `section`, `article`, `address`, `footer`).
- **CSS3** — קובץ עיצוב חיצוני יחיד (`style.css`), משתני CSS, Flexbox ו-Grid.
- **ללא JavaScript.**

## תכונות
- 🌗 מתג מצב כהה/בהיר — ממומש ב-CSS בלבד (טכניקת checkbox + `:has()`).
- 📱 עיצוב רספונסיבי — מותאם למובייל, טאבלט, דסקטופ ומסכים גדולים.
- ♿ נגישות — תגיות סמנטיות, `alt`, `aria-label` ומיקוד מקלדת.

## מבנה הקבצים
```
├── index.html        # מבנה העמוד
├── style.css          # כל העיצוב
├── assets/
│   └── profile.svg    # תמונת פרופיל (זמנית — ניתן להחליף)
└── README.md
```

## הרצה מקומית
פשוט לפתוח את `index.html` בכל דפדפן.
